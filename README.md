# WEBGIS SPATIAL POVERTY KOTAWARINGIN TIMUR EVAN 2025
# **🌍 WebGIS Spatial Poverty Kabupaten Kotawaringin Timur**

WebGIS ini dikembangkan sebagai media informasi spasial yang menampilkan hasil analisis 
dan visualisasi sebagian kecil dari tesis saya yang berjudul  "Variasi Spasial Pembentuk Karakteristik Kemiskinan Di Kabupaten Kotawaringin Timur"
(https://etd.repository.ugm.ac.id/penelitian/detail/256216). Webgis ini bertujuan mendukung pembelajaran, penelitian, dan pengembangan pengetahuan di bidang 
Perencanaan Wilayah dan Kota.

# **🧭 Tujuan**
1. Menyajikan informasi spasial dalam bentuk peta interaktif.
2. Menampilkan hasil analisis spasial seperti persebaran fasilitas, klaster kemiskinan, dan kondisi wilayah.
3. Mendukung kegiatan pendidikan, penelitian, dan pengambilan wawasan berbasis data spasial.

# **🗺️ Sumber Data**

Data yang digunakan berasal dari berbagai sumber terbuka dan hasil olahan penulis:
1. OpenStreetMap – Data jaringan jalan dan batas wilayah.
2. Badan Pusat Statistik (BPS) – Data kependudukan dan sosial ekonomi.
3. Pengolahan Penulis – Menggunakan perangkat lunak :
4. QGIS – Analisis dan visualisasi spasial

# **⚠️ Disclaimer**

Seluruh peta, data, dan analisis dalam WebGIS ini:
Bersifat non-komersial.
Ditujukan semata-mata untuk kepentingan pendidikan dan penelitian.
Tidak dapat dijadikan dasar hukum maupun keputusan kebijakan resmi.
Akurasi spasial maupun atribut data dapat bervariasi tergantung pada sumber data dan metode analisis yang digunakan.

1. Mengutip informasi dari WebGIS ini dengan mencantumkan sumber yang sesuai.
